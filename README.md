# 墨痕武道：水墨火柴人 (Ink Martial: Stickman Roguelike)

一款具有浓郁中国古典水墨美学风格的**仿3D火柴人动作肉鸽战斗游戏**。游戏支持键鼠操作与触屏手势识别，独创"**指哪打哪 · 全屏跟手瞬杀**"与"**水墨书法手势连斩**"交互系统，融合了骨骼动画打击感、敌人受击硬直（破势）机制与多重肉鸽技能词条随机组合。

提供**经典征战 / 无双演武**两种玩法模式、**初入江湖 / 炉火纯青 / 宗师绝顶 / 天劫墨难**四档试炼难度，35 种肉鸽武道词条自由构筑，并支持单局快照续战与战绩导入导出。

## 游戏核心特性

1. **水墨书法手势与指哪打哪战斗体系**：
   - **全屏跟手位移**：手指在屏幕上滑动，火柴人以极高响应速度紧随指尖移动，留下水墨残影与墨迹尘烟。
   - **到达自动拔剑斩击**：手指离开屏幕瞬间，角色到达终点并自动拔剑释放凌厉斩击（智能索敌面朝最近敌人）。
   - **多目标划敌瞬杀连击**：一笔划过多个敌人，自动触发高速穿梭闪避斩击，空中爆发朱砂与焦墨交织的**剑意连接特效（Slash Links）**与古印章篆刻。
   - **空中千斤坠**：从空中滑步落地时自动触发震撼地面的下砸冲击波。
   - **书法招式识别**：书写『一』字横扫千军、竖劈力劈华山、挑空飞燕凌空、画圆浑元太极盾、折线踏影瞬杀。

2. **敌人受击硬直机制（破势与定身）**：
   - 击中敌人强制打断其前摇与蓄力攻击；
   - 产生 0.45s ~ 0.75s 受击硬直（伴随身体后仰、墨迹高频震颤与『⚡破势』提示），重置攻击冷却；
   - Boss 首领具备武道宗师韧性，需连击破势。

3. **攻击前摇预警系统（新增）**：
   - 所有近战敌人出手前头顶亮起红色「！」并后坐蓄力（0.4s~0.6s）；
   - 蓄力期间挥剑命中即可**打断攻击**——将「破势」从奖励机制升级为反制博弈核心。

4. **Boss 三强线体系（v6 扩充）**：
   - **第5折·墨煞先锋**（焦赭窄笠+肩刺，轻装快攻）：墨刃突进（橙色预警圈锁定落点后 620px/s 直线冲撞，横向走位可躲）+ 小震地 + 召唤 1 墨卒，半血狂暴；
   - **第10折·墨煞宗师**（暗赤，原宗师）：震岳一击（红圈预警 0.9s 走位可躲）+ 墨珠五连散射 + 半血解锁召唤，半血狂暴；
   - **第15折·墨煞大帝**（玄墨金边宽笠+金穗，终折）：震地范围 112、墨珠七连散射、召唤 2-3 墨卒；**三阶段**——66% 狂暴（金红双环光环）、33% 入「灭」境：解锁**落墨成渊**全场五连环墨雨（连环橙圈先后炸落）+ 全技能冷却 28% 缩短 + 移速 +50%；
   - **无尽再临**：20 折起每 5 折大帝再临（再临/第三袭/第四袭…），数值随折数继续攀升。

5. **精英词缀系统（新增）**：
   - 第三折起随机出现精锐（每波至多 2 名），带彩色光环与顶标；
   - **迅捷**（移速+45%）、**铁壁**（血量+90%，大幅抗击退）、**狂暴**（伤害+50%，攻速+45%）、**汲影**（攻击吸血）；
   - 斩杀精英获额外功绩与墨意。

## 玩法模式：经典征战 / 无双演武

两种模式在标题界面任选，**战绩分榜互不污染**（经典「江湖行录」/ 无双「无双血录」，导入导出智能合并兼容）。

| | 经典征战 | 无双演武 |
|---|---|---|
| 目标 | 十五折问鼎墨武之巅，胜后可入无尽 | 无通关概念，力战而竭即止 |
| 每阵敌数 | 5 + 3×折（上限 42） | 10 + 5×阵（上限 60） |
| 刷怪间隔 | 基准 | ×0.26，第 2 阵起 50% 簇刷成群 |

| 单体血量 | 基准 | 妖墨 ×0.62、Boss ×0.52（防磨血拖节奏） |
| 墨经济 | 回墨 14/秒，击杀回墨 15（精英 25） | 回墨 18/秒，击杀回墨 30（精英 42），手势墨耗 ×0.55 |

### 无双 v2「势如潮涌」两大新机制

- **连招链**：连续出招间隔小于 1.8s 即叠层，**变招**一次涨 2 层（同招涨 1 层）；每层 +12% 伤害、+7% 范围（上限 +72% / +50%），超时清零——鼓励交替施招而非复读同一招。
- **斩罡余波**：每一击都荡开半径 125 的墨浪波及周身妖墨（40% 基础伤害计入连击），**任意招式皆成群体技**；配合攻击范围横 ×1.3 / 纵 ×1.5，怪海中一刀扫倒一片。

## 快速启动运行指南

### 环境要求
- Node.js 18.0 或更高版本
- npm / pnpm / yarn / bun

### 1. 安装依赖
```bash
npm install
```

### 2. 本地开发运行
```bash
npm run dev
```
启动后在浏览器打开控制台输出的地址（默认 `http://localhost:3000`）即可开始游玩。

### 3. 项目打包构建
```bash
npm run build
```
构建产物将输出在 `dist/` 目录中。

## 操作指南

### 触屏操作（移动端/平板）：
- **全屏挥墨模式（推荐）**：
  - 手指在屏幕上滑动：角色极致跟手移动，松手瞬间自动拔剑斩击；
  - 划过敌人：触发【瞬杀连斩】，目标间呈现水墨连击锁链；
  - 轻点空地：施展【踏雪寻梅】身法位移；
  - 画出特定轨迹：释放太极盾、裂地斩、挑空击等书法招式；
  - 敌人头顶出现红色「！」时，滑步走位或打断其蓄力。
- **分屏双控模式**：
  - 左半屏：拖动摇杆控制走位与起跃；
  - 右半屏：挥动画笔书写招式。

### 键盘操作（PC端）：
- **移动**：`W`（向深处走）、`S`（向镜头走）、`A`（向左跑）、`D`（向右跑）
- **起跃轻功**：`空格键 (Space)` 或 `K`
- **暂停**：`ESC`
- **书法武学快捷键**：
  - `J`：墨刺连击
  - `U`：横扫千军（释放穿透剑气）
  - `I`：力劈华山（大地震颤地刺）
  - `O`：浑元太极（太极八卦反弹护盾）
  - `L`：踏影瞬杀（疾速穿梭斩击）
- **觉醒技**：`G` —— 觉醒槽满后释放「万墨归宗」全屏墨爆（也可点 HUD「觉」按钮）

> **无双演武小贴士**：连续出招间隔小于 1.8 秒即叠「连招链」，**交替不同招式**每层涨 2 级（同招涨 1 级），最多 +72% 伤害 / +50% 范围——别复读同一招。

## 觉醒技：万墨归宗（v10 重做）

- **充能**：命中 +2.5（暴击 +4.5）、击杀 +6（无双模式命中再 ×1.3、击杀 +9）；「墨魂涌动」充能 +30%、「玄武镇岳」每波开战直接 +50（半槽白送）——怪海中几秒即可充满。
- **释放**：满槽后按 `G` 或点 HUD「觉」按钮——全屏半径 **560**（无双再 ×1.15 = 644，「气吞山河」再 +50%）墨浪爆发，**一发覆盖近半战场**；附带大范围击退与 0.95s 长时间硬直，并**绕过墨盾武僧的正面格挡**全额结算。
- **伤害**：基础 **320**（原 90）× 词条攻击加成 × 觉醒伤害加成（「万墨归一」+60%）× 无双连招链层数；**35% 真·暴击**（本次实乘暴击倍率）；对首领额外追加其最大气血 **6%**、精英 **3%** 的压制伤害——高阵 Boss 血量线性成长也压得住。
- **演出与收益**：慢动作 0.55s + 镜头冲击 + 双激波 + 地裂 + 屏缘泼墨 + 金色大字（命中 18 只以上追加「荡」字）；释放后短暂无敌 **1 秒**并回补 20 墨意——绝境反打的保命底牌。
- **性能护栏**：怪海下仅前 24 只播放全额墨花与浮字，其余静默结算，保证帧率不塌。

## 性能优化（v3）
- **离屏静态图层缓存**：宣纸底色渐变、暖墨暗角、受击红晕、低血红晕、屏缘泼墨（含四角晕点）、慢动作上下墨帘全部预烘焙为离屏 Canvas，每帧仅 `drawImage` 一次（受击/低血用 `globalAlpha` 实时调制强度），消除每帧的渐变重建与全屏径向填充；窗口 resize / DPR 变化时自动作废重建
- **地面渐变缓存**：宣纸地面 `CanvasGradient` 只在尺寸变化时重建
- **零分配热路径**：粒子/弹道/敌人/浮字/剑弧/墨渍/激波环/残影/预警圈全部改为原地压实（in-place compaction），取代每帧 `filter()` 产生的新数组；渲染投影改用共享 scratch（`projectXYZ`），粒子渲染内联投影数学，单帧零对象分配
- **屏幕外剔除**：敌人（±150px）/弹道（±90px）/残影/粒子/浮字/墨渍/激波环/剑弧出屏即跳过，镜头远处的敌群不再消耗骨架绘制
- **shadowBlur 清零**：浮动战斗数字、前摇「！」、破势标记改用宣纸色 `strokeText` 描边（视觉等效，开销大幅降低）
- **逐帧数学提升**：击退阻尼、墨魂阻尼等 `Math.pow` 每帧计算一次；`performance.now()` 每帧缓存
- **自适应画质**：帧耗时 EMA 每 2s 判定一次（>24ms 降一档、>33ms 直降最低档，只降不升防震荡），逐级下调粒子上限 460→280→150、环境飘墨 26→16→8、弹道尾迹概率 0.62→0.28，标签页切回的大帧间隔不纳入统计
- **实测数据**（1920×1080，22 敌 + 460 粒子 + 14 剑弧 + 26 墨渍 + 20 浮字同时渲染）：`render()` 平均 1.06ms、`update()` 平均 0.09ms，理论帧余量 >700fps；实际战斗 60fps（vsync 上限），全程控制台零报错

## 性能优化（v4 · 防卡死专项）
- **引擎生命周期 destroy()**：新增 `destroy()` 方法（停止循环 + 移除全部 window/document/canvas 事件监听），React 卸载时调用——修复旧引擎僵尸监听器永久持有整局世界状态的内存泄漏（长时间反复开局在移动端可累积至 OOM 卡死）
- **同屏妖墨上限**：生成器加拥挤保护——经典模式存活妖墨达 22 只（无双 34 只）时推迟生成（不消耗波次配额，经典 0.75s / 无双 0.4s 后重试；Boss 本体豁免），怪海清怪速度跟不上生成速度时敌人不再无界堆积压垮帧率
- **无尽波次软上限**：单波敌人数封顶 42 只，后期压力靠妖墨构成（自爆/格挡/召唤）而非无界数量
- **暂停渲染冻结**：暂停/结算画面世界静止，仅在脏标记（暂停切换/resize/画质降档/重开）时重绘一帧——实测暂停 3 秒 `drawImage` 调用为 0（优化前为 ~180 次全量重绘），消除移动端挂机暂停的持续发热与热降频卡顿
- **移动端切后台保护**：新增 `visibilitychange` 监听（iOS Safari 切后台常不触发 blur）——隐藏时自动暂停 + 释放触点，回前台重置时间基准（防大帧跳变）并唤醒 AudioContext
- **音频零分配**：笔触/挥剑的噪声声源改用预生成共享白噪声缓冲池（4×0.5s，AudioBuffer 不可变可并发播放），滑砍时不再每次调用都新建并逐样本填充 AudioBuffer（原每秒可达 20-30 次分配）
- **BGM 生命周期**：暂停/返回标题/卸载时停止古琴循环定时器（防后台空转耗电），恢复游戏自动续播；静音开局后解除静音 BGM 可自动恢复
- **长笔迹保护**：手势笔迹超 320 点自动淘汰最旧四分之一，超长拖拽不再无界累积内存与识别耗时
- **实测数据**（headless Chromium 软渲染）：战斗中 42fps（同环境标题界面基准 26fps，战斗渲染预算显著优于静态页）；暂停 3s 渲染调用 0 次；完整会话（战斗 + 两次暂停/恢复循环 + 死亡结算 + 重开）JS 堆稳定在 3.8MB 零增长；击杀→计分→波次计数联动验证通过；全程控制台零报错

## 移动端优化（v7 · 掌上泼墨）
- **迷你状态条**：手机此前完全看不到气血/墨意/觉醒（原状态栏在窄屏整体隐藏）——新增移动端专属 2×2 迷你状态条（气血/墨意/觉醒/妖墨余量，持盾时追加墨盾跨列条），半透明宣纸面板置于顶部栏下方，桌面端自动隐藏
- **底部触控区重划**：底部操作行容器由整行拦截触控改为仅按钮簇可点——左下角完全让给虚拟摇杆/划砍区（实测 `elementFromPoint` 直抵画布）；「跃/觉」按钮移入右侧与六技能合并为统一动作簇，分屏模式左拇指不再误触跳跃
- **触屏快捷键自适应**：移动端隐藏「刺」按钮（右屏轻点即刺，快捷键冗余），7 键布局在 360px 极限窄屏亦无横向溢出（390px/360px/844×390 三档视口实测 overflow=0）
- **刘海屏安全区**：`viewport-fit=cover` + HUD 四边 `env(safe-area-inset-*)` 适配，刘海/手势横条不再遮挡顶栏与动作键；Boss 血条改文档流排列，与迷你状态条永不重叠
- **竖屏体验提示**：触屏设备竖屏游玩时出现「横屏执笔 · 挥洒更自如」一次性提示（点击「知道了」后 localStorage 永久记住，转横屏自动消失）
- **笔锋指引**：触屏设备笔迹末端上方渲染朱砂小圈标记实际笔锋位置（指尖遮挡触点时也能看清划到哪），桌面端不受影响
- **触屏渲染性能**：粗指针设备 DPR 上限 2→1.75（水墨笔触柔和，肉眼无损），高分屏手机省约 1/4 像素填充；配合既有自适应画质降档双保险
- **触控细节**：全局去除点按灰色高亮（`-webkit-tap-highlight-color`）、禁橡皮筋回弹（`overscroll-behavior: none`）；顶部栏/提示行/字号按窄屏压缩（waveTitle 超长自动截断）

## 项目技术栈
- **框架**：React 19 + TypeScript + Vite
- **动画与样式**：Tailwind CSS + Lucide Icons + Procedural Canvas 2D
- **音效合成**：Web Audio API 自研水墨古筝与打击声效合成器（Master GainNode 音量总线）
- **骨骼与物理引擎**：自研轻量级伪3D正交透视物理与动力学骨骼算法
- **进程持久化**：localStorage 江湖行录
